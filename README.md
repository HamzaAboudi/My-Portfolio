# My Portfolio

A modern, responsive portfolio to showcase my projects, skills, and design work.

## 🚀 Features

- **Clean, modern design** with smooth animations and transitions
- **Responsive layout** that works on mobile, tablet, and desktop
- **Skill showcase** with technology icons
- **Project gallery** with thumbnails and descriptions
- **Smooth scroll animations** with reveal effects
- **GitHub Pages** hosting for continuous online availability

## 📝 Recent Changes (Latest Update)

### Enhanced Skills Section
- **Added technology icons** using Devicon library for visual representation
- Skills now display as interactive icon cards with hover effects
- Improved visual hierarchy with better spacing and typography
- Categories: Frontend, Backend & Programming, Design, Workflow & Mindset

### Project Cards Improvements
- **Added project thumbnails** for visual previews
- Implemented cleaner project summaries (shorter, more impactful descriptions)
- Added styled action buttons (View Website / View GitHub Repo links)
- Removed verbose bullet-point lists in favor of concise summaries
- Added reveal animations with directional effects (up, down, left, right)

### Styling Enhancements
- New `.btn.small` class for compact button styling
- `.skill-icons` layout using flexbox with icon-focused cards
- `.project-thumb` styling with gradient borders and hover image zoom
- Improved hover states with subtle transforms and shadows
- Better visual feedback on interactive elements

## 🛠️ Technologies Used

- **HTML5** – Semantic markup and accessibility
- **CSS3** – Responsive design, flexbox, animations
- **JavaScript** – DOM interactions and reveal effects
- **Devicon** – Technology icon library
